# 1D nanobeam design process: figures

Generated by `python docs/design_process/make_all.py [--pull]`; numbered in presentation order.

- **01_si_snowflake_cell.png**: Si snowflake unit cell (a 478, t 220): rhombus primitive cell, Floquet BCs, symmetric / antisymmetric classes.

- **03_si_validation.png**: Validation: Python-driven COMSOL vs GUI (mechanical spot checks at Gamma, M, K; optical at Gamma).

- **12_candidate_mirror_bands.png**: Optical and mechanical bands of the strongest candidate mirror cells.
